How to Use

1) Choose a test

Reaction Time or Go / No-Go.

2) Build your baseline (first time)

  • Be rested and functioning normally
  • Use the same device and input method
  • Complete 3–5 baseline sessions

Baseline sessions define your personal normal range.

3) Run a functional check

  • Run a short check session
  • Results are compared to your baseline
  • Status is shown as:
    • Within normal range
    • Slightly below normal
    • Significantly below normal

4) Review history and trends

  • View past sessions in History
  • See baseline range and recent checks in the Trend panel
  • Optional context tags help interpret variation

5) Export data (optional)

  • History can be exported as JSON
  • Export is manual and local-only

Hvordan bruke FCE

1) Velg en test

Reaksjonstid eller Go / No-Go.

2) Bygg din baseline (første gang)

  • Vær uthvilt og fungerer normalt
  • Bruk samme enhet og inndatametode
  • Fullfør 3–5 baseline-økter

Baseline-økter definerer ditt personlige normalområde.

3) Kjør en funksjonssjekk

  • Gjennomfør en kort sjekk-økt
  • Resultater sammenlignes med din baseline
  • Status vises som:
    • Innenfor normalområdet
    • Lett under normalområdet
    • Betydelig under normalområdet

4) Gjennomse historikk og trender

  • Se tidligere økter i Historikk
  • Se baselineområde og nylige sjekker i Trend-panelet
  • Valgfrie konteksttagger hjelper med å tolke variasjon

5) Eksporter data (valgfritt)

  • Historikk kan eksporteres som JSON
  • Eksport er manuell og kun lokalt
